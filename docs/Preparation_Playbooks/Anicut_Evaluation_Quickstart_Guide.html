03. OpenAI Drop-In API Code Samples

How developers switch from expensive centralized cloud GPUs to FlockML in 1 line:

PYTHON (STANDARD OPENAI SDK)
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="flock_local_eval"
)

response = client.chat.completions.create(
    model="llama-3-70b-flock",
    messages=[{"role": "user", "content": "Hello"}]
)
print(response.choices[0].message.content)
cURL (REST ENDPOINT)
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer flock_local_eval" \
  -d '{
    "model": "llama-3-70b-flock",
    "messages": [
      {"role": "user", "content": "Explain FlockML"}
    ]
  }'
