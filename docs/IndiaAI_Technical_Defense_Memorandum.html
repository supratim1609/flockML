1.0 Executive Overview

The core challenge of the ₹10,372 Crore IndiaAI Mission is providing affordable, domestic computing capacity without becoming structurally dependent on foreign hyperscale cloud providers (AWS, Microsoft Azure, Google Cloud). Procuring dedicated Nvidia H100/H200 GPU clusters is capital-intensive (₹2.5 Crore+ per 8-GPU server) and subject to international supply chain delays.

FlockML provides a pure software infrastructure that clusters existing, idle domestic hardware (such as broadband fiber set-top boxes, institutional desktop PCs, and enterprise workstations) into a high-performance, decentralized inference mesh. It achieves a 70% cost reduction ($0.27 / 1M tokens vs. $0.90 on AWS Bedrock) while ensuring 100% data sovereignty on Indian soil.

2.0 Question 1: Network Drops, High Latency & Variable Connectivity

"How does FlockML maintain continuous execution across Tier-1, Tier-2, and rural Indian network environments where connectivity may fluctuate?"

FlockML avoids streaming heavy neural network weights over the network by separating static model parameters from runtime activations:

  • Permanent Local Layer Caching: Model weights are loaded once into local device memory (WebGPU VRAM or RAM). Weights are never transferred over the wire during inference.
  • Lightweight Activation Vectors: Nodes only pass a small intermediate mathematical vector (hidden-state activation vector of dimension 4,096) representing the hidden state after a layer completes. For a 70B parameter model, this payload is merely ~8.2 Kilobytes per token, transmitting over standard 4G or broadband in under 2 milliseconds.
  • Sub-5ms Work-Stealing Failover: If an edge node experiences packet loss, disconnects from Wi-Fi, or lags by > 30ms, the coordinator’s work-stealing scheduler immediately detects the node drop and routes the remaining layers to an adjacent healthy node in < 4.8ms with zero token loss.

3.1 Operational Integrity, Thermal Safety & Byzantine Protection

To ensure operational safety across diverse physical environments, FlockML enforces four strict engineering safeguards:

  • Byzantine Fault Tolerance: Worker nodes emit a deterministic cryptographic hash commitment for each computed layer. The coordinator performs redundant parity sampling (1 in 50 tokens evaluated across dual nodes). Any compromised node attempting numerical tampering is blacklisted in < 0.1 milliseconds.
  • Thermal Gating & Zero Battery Impact: Compute executes strictly when devices are connected to AC wall power and idle, auto-throttling if device thermal sensors detect temperatures above 42°C.
  • Minimal Data Consumption: Communication is restricted to ~8.2 KB activation tensors per token; processing 100,000 tokens consumes approximately 800 Megabytes across a full month.
  • Air-Gapped Operation: For strategic environments (ISRO / defense), the cluster operates over an isolated, closed-loop local subnet (LAN) with zero internet dependency.
